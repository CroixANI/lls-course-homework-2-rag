
Вызови `_build_bm25_index()` после успешной загрузки `chunks` в `_ensure_index_exists()`.

### 3.2. Алгоритм RRF (Reciprocal Rank Fusion)

RRF объединяет два ранжированных списка в один. Формула для каждого документа:

```
RRF_score(d) = Σ 1 / (k + rank(d))
```

где `k = 60` (стандартное значение), `rank(d)` — позиция документа в каждом списке (начиная с 1).

Реализуй отдельную функцию:

```python
def _rrf_fusion(vector_ids: list[int], bm25_ids: list[int], k: int = 60) -> list[int]:
    """
    Объединяет два списка id чанков через Reciprocal Rank Fusion.
    Возвращает список id, отсортированных по убыванию RRF-score.
    """
    scores = {}
    for rank, idx in enumerate(vector_ids, start=1):
        scores[idx] = scores.get(idx, 0) + 1 / (k + rank)
    for rank, idx in enumerate(bm25_ids, start=1):
        scores[idx] = scores.get(idx, 0) + 1 / (k + rank)
    
    return sorted(scores, key=lambda i: scores[i], reverse=True)
```

### 3.3. Обнови функцию `retrieve()`

Замени текущую реализацию `retrieve()` на гибридную. Логика:

1. Выполни **векторный поиск** через FAISS — получи Top-`TOP_K * 4` кандидатов (берём больше, чтобы было из чего выбирать после слияния)
2. Выполни **BM25-поиск** — получи Top-`TOP_K * 4` кандидатов
3. Объедини результаты через `_rrf_fusion()`
4. Возьми первые `TOP_K` результатов из слитого списка
5. Выведи лог по каждому найденному чанку (сохрани существующий формат `[RAG]`)

Пример обновлённой функции:

```python
def retrieve(query: str) -> list[dict]:
    if index is None or len(chunks) == 0:
        if not _ensure_index_exists():
            return []
    
    candidates = TOP_K * 4

    # Векторный поиск
    q_emb = model.encode([query])
    faiss.normalize_L2(q_emb)
    vector_scores, vector_ids_raw = index.search(q_emb, candidates)
    vector_ids = [int(i) for i in vector_ids_raw[0] if i >= 0]

    # BM25-поиск
    tokenized_query = query.lower().split()
    bm25_scores = bm25.get_scores(tokenized_query)
    bm25_ids = sorted(range(len(bm25_scores)), key=lambda i: bm25_scores[i], reverse=True)[:candidates]

    # RRF-объединение
    fused_ids = _rrf_fusion(vector_ids, bm25_ids)[:TOP_K]

    print(f'[RAG][Hybrid] Найдено чанков: {len(fused_ids)} для запроса: "{query}"')
    for rank, idx in enumerate(fused_ids, start=1):
        chunk = chunks[idx]
        preview = chunk['text'][:80].replace('\n', ' ')
        v_score = float(vector_scores[0][vector_ids.index(idx)]) if idx in vector_ids else 0.0
        b_score = float(bm25_scores[idx])
        print(f'[RAG] #{rank} | vector={v_score:.4f} | bm25={b_score:.4f} | source={chunk["source"]} | "{preview}"')

    return [chunks[i] for i in fused_ids]
```
