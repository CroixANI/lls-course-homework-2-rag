# Первые промпты

## Попросил Claude Code написать промпты за меня

```txt
у меня домашние задание на курсе изучения LLM.
"Студент должен составить файл search-spec.md, который описывает три новых уровня обработки.
1. Hybrid Search (BM25 + Vector)
* Задача: Реализовать поиск по ключевым словам (BM25) параллельно с векторным.
* Спецификация: Описать алгоритм RRF (Reciprocal Rank Fusion) или Weighted Sum для объединения результатов.
* Зачем: Чтобы поиск по запросу 403 Forbidden находил именно этот код, а не просто «что-то про ошибки».
2. Reranking (Cross-Encoder)
* Задача: Внедрить второй этап фильтрации.
* Спецификация: 1. Получить Top-20 результатов из гибридного поиска. 2. Прогнать их через легковесный реранкер (например, BAAI/bge-reranker-base через локальную библиотеку или ту же Ollama/ONNX). 3. Отдать в LLM только Top-5 самых релевантных.
* Зачем: Убрать «шум» и оставить только те куски, которые реально отвечают на вопрос.
3. Query Expansion (LLM Rewrite)
* Задача: Добавить этап «умного» перефразирования.
* Спецификация: Если запрос слишком короткий или содержит аббревиатуры (например, sqli), агент должен сначала расширить его до SQL Injection vulnerability examples, а затем уже искать."
 
Для пунктов 1,2 и 3 создай отдельные prompts. Сохрание их в папку "prompts". 
* Для шага 1 файл должен называться "2.1-new-feature-hybrid-search-prompt.md"
* Для шага 2 файл должен называться "2.2-new-feature-rerangking-prompt.md"
* Для шага 3 файл должен называться "2.3-new-feature-query-expansion-prompt.md"

Важно
* Каждый prompt должен быть на русском языке.
* Учти, что эти prompt-ы буду запускаться с помощью Claude Code.
* Если требуется, то добавь, что Claude Code должен изучить код или задавать мне вопросы в случае если что-то не понятно.
```
